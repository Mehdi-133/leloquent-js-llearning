## ✅ Verification rule

An image becomes verified only when:

- it is stored in the repository or linked from its owning concept;
- its technical meaning is correct;
- it is readable in the rendered slide;
- its explanation tells the audience what to notice and why it matters;
- its source and usage location are recorded in the table above.
