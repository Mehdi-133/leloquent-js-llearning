# 🖥️ Slide Plan

The presentation uses exactly eight slides:

1. JavaScript Data Structures
2. From a Simple Value to Structured Data
3. `Array`: An Ordered Collection
4. `Object`: One Structured Entity
5. `Map`: Lookup by Key
6. `Set`: Unique Values
7. Traverse, Search, Filter, Sort, and Group
8. Final Decision Framework and Mini-Cases

## 🎨 Design direction

- Professional yellow, charcoal, cream, and white palette
- Strong contrast and generous spacing
- Dark monospace code cards
- One main idea and one compact code example per slide
- Exactly eight slides with no crowded paragraphs
