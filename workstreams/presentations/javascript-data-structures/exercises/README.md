# 🧪 Presentation Exercises

Audience exercises and prediction questions belong here.

## Planned mini-cases

1. Resources contain repeated categories: choose a structure that produces unique categories.
2. Retrieve one learner's progress using a known `courseId`: choose between an array, object, or `Map`.

## Exercise rule

Show the problem first, allow the audience to choose, then reveal the answer and explain why.

> 📚 Book exercises remain in the Chapter 4 folder; this folder contains only presentation-specific practice.
