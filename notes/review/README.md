# Review Notes

Use this folder for short notes about concepts explained during learning sessions.

## Format

- Create one Markdown file per topic.
- Use a short kebab-case filename, such as `express-zod-validation.md`.
- Keep each note focused on the main idea, important methods, common errors, and the next review question.
- Prefer five clear bullet points when a short summary is enough.
- Add every new note to the index below.
