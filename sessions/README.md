# Session Handoffs

`CURRENT.md` is the first file a new assistant should use to resume the learning process. Keep it short, factual, and specific.

For a substantial milestone, copy the completed handoff into `history/` using this name format:

```text
YYYY-MM-DD-short-topic.md
```

Do not create a history file for trivial wording changes. Use `templates/session-log.md` for the structure.
