# Chapter Workspaces

The chapter folders mirror the three parts of the book:

- `part-1-language/` - Chapters 1-12
- `part-2-browser/` - Chapters 13-19
- `part-3-node/` - Chapters 20-21

Only create a numbered chapter folder when that chapter begins. Use `templates/chapter-readme.md` so every future session can quickly understand the chapter state.

Inside a chapter, use these folders when needed:

```text
NN-chapter-title/
|-- README.md       # Goals, status, discoveries, and verification
|-- examples/       # Book examples typed and explored
|-- exercises/      # Learner exercise solutions
`-- experiments/    # Variations used to test understanding
```
