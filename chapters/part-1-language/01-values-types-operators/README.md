## Learning goals

By the end of this chapter, the learner should be able to:

- Explain what a JavaScript value and type are.
- Use number, string, Boolean, `null`, and `undefined` values.
- Use arithmetic, comparison, logical, and unary operators.
- Predict operator precedence in simple expressions.
- Explain the difference between `==` and `===` at a beginner level.
- Recognize when automatic type conversion can create surprising results.
